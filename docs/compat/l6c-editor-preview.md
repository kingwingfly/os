# L6c: Editor (`/usr/bin/editor`) and Preview (`/usr/bin/preview`) as Ordinary GUI Processes

Issue `#64` replaces the retired in-page CodeMirror/DOM Editor (`#editor`, `web/editor.mjs`) and Leptos/DOM Preview (`#viewer`, `crates/frontend/src/{viewer,preview,search,workers,manual}.rs`, `web/{dev,sound,record}.mjs`) with two ordinary unprivileged WASI GUI Document processes that communicate strictly over standard POSIX syscalls, `AF_UNIX` sockets (`SO_PEERCRED` + `SCM_RIGHTS`), and GUI v1 `/run/gui/seat0.sock`, retiring the entire `SurfaceKind::Host` Window compatibility path (`APPS`, `createCompatSurface`, `gui-compat-event`) from the desktop shell:

- **`/usr/bin/editor`** (`crates/services/src/editor.rs`, `crates/services/src/bin/editor.rs`, bundle `/usr/share/gui/editor/editor.json`): Ordinary GUI v1 client presenting `SurfaceRole::Window` + `SurfaceKind::Document` (`app_id: "editor"`). Reads and saves files directly via POSIX syscalls with conditional revision checking (`ESTALE` / `EEXIST` / `ENOENT` conflict banners preserving unsaved drafts and explicit discard confirmation), syntax-highlights code inside the sealed CodeMirror Document iframe, supports `--wait` for synchronous `vim` exit status, persists local drafts and read-only detection (`EACCES` -> Read-only toolbar), and exports buffers via compositor-gated `ClientReq::ExportFile`.
- **`/usr/bin/preview`** (`crates/services/src/preview.rs`, `crates/services/src/bin/preview.rs`, bundle `/usr/share/gui/preview/preview.json`): Ordinary GUI v1 client presenting `SurfaceRole::Window` + `SurfaceKind::Document` (`app_id: "preview"`). Renders Markdown (with MathML, KaTeX-free `pulldown-latex`, `ammonia` HTML sanitization, relative VFS image resolution, and clickable relative VFS links with Back navigation trail), slides (keyboard/touch/overview/enlarged image/theme selector/inline & popup `--speaker` view), PDFs (scroll & single-page present modes), syntax-highlighted code/text/diffs/CSV/vCard/iCal/manuals (`man`), archives (`.zip`, `.tar`, `.tgz`, `.tar.gz`), images (SVG rendered strictly as sanitized `data:image/svg+xml` inside `<img>`), audio/video (via `StreamAsset` `Blob` or `RangePull`), and validated `.game` manifests (checked against read-only `/usr/share/os/config.json`). Maintains a single-instance control socket `/run/user/<uid>/preview.sock` (`0600`, `SO_PEERCRED`-checked; skipped under `--speaker`) and persists per-file reading positions, slide themes, and notes font size atomically in `~/.local/state/os/preview/places.json` (version 1, Contract v2 §2.12).
- **Blind Host Media & Session Broker (`web/gui/media-broker.js`)**: Replaces `web/{dev,sound,record}.mjs`. Owns strictly browser-only Window APIs (`RTCPeerConnection`, `navigator.mediaDevices.getUserMedia`, `MediaRecorder`, `#listening` `<audio>` elements, `BroadcastChannel('os-present')`, `window.open('/?speaker=...')`, and `WebSocket('/api/events')`) with zero boot network requests; `/api/events` connects only when Cloud-signed-in or when an active presentation/live-sound subscription requests it.

## Privilege & Isolation Invariants

1. **Zero `gui_*` Wasm imports or exports**: Neither `/usr/bin/editor` nor `/usr/bin/preview` imports or exports any `gui_*` host function (verified automatically in `tests/gui-protocol.test.mjs`).
2. **All Window `SurfaceKind::Host` compatibility components retired**: `"editor"` and `"viewer"` are removed from `compositor.rs`'s `SurfaceKind::Host` allowlist (leaving zero Window Host components) and all Window compat plumbing (`APPS`, `createCompatSurface`, `destroyCompatSurface`, `gui-compat-event`, `setCompatOpen`) is deleted from `web/gui/compat-bridge.js` and `crates/frontend/src/desktop.rs`. Any peer requesting `SurfaceKind::Host { component: "terminal" | "files" | "mounts" | "editor" | "viewer" }` receives `EPERM`.
3. **Frozen syscall ABI & zero new external crates**: `crates/abi/src/lib.rs` (`abi::Call`, 74 variants) is untouched (`node scripts/conformance/check-abi.mjs`), and `Cargo.lock` adds zero new external crates (moving five existing workspace crates `ammonia`, `csv`, `os-preview`, `pulldown-cmark`, and `pulldown-latex` from `os-ui` to `os-services`).
4. **Sealed opaque Document frames**: Both bundles render inside `sandbox="allow-scripts"` `srcdoc` iframes with pinned SHA-256 CSP (`default-src 'none'`, `connect-src 'none'`, `frame-src 'none'`, `object-src 'none'`), opaque `'null'` origin, zero `window.os` / `fetch` access, and 4096-byte UTF-8 frame chunking (`os_services::gui_doc`).
5. **Typed `SCM_RIGHTS` kernel descriptor pinning (`PIN_FD` / `UNPIN_SURFACE`)**: `/usr/bin/preview` passes already-authorized read-only descriptors via `SCM_RIGHTS` on `StreamAsset`, `PreviewJob` (`PdfOpen`, `ListArchive`), and fd-backed `ExportFile`. The compositor validates surface ownership and pins the open file description inside the client-kernel Worker (`PinnedGuiFd`), which streams bytes over the surface's private `MessagePort` (`asset-chunk`/`asset-eof` or `asset-ready`/`asset-range`) or feeds kernel-hosted lazy preview Workers (`web/kernel/preview-workers.js`) without ever giving the page or iframe direct VFS paths or `/api/file` authority. All pins for a surface are automatically released on `ReleaseAsset`, completion, or surface teardown (`UNPIN_SURFACE`).
6. **Trusted host-event fencing**: `web/kernel/client.js` rejects forged `fullscreen_changed`, `preview_job_result`, `media_event`, and `session_event` frames over `gui_host_event` with `EACCES`; only the dedicated Worker/host callbacks (`gui_fullscreen_result`, `gui_media_event`, `gui_session_event`, and Worker-internal preview-job completions) may inject them. Fullscreen entry, file export (`ExportFile`), speaker popup (`OpenSpeaker`), and live microphone/recording (`GoLive`) require a fresh trusted user gesture (`EACCES` otherwise).
